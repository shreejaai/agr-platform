The Solution

One SDK call.
Complete governance.

# Install pip install agr-sdk # Wrap your agent tool call from agr import AGRClient agr = AGRClient(api_key="agr_sk_...") result = agr.evaluate( agent="finance-bot", action="transfer_funds", resource="account:123", context={"amount": 500000} ) if result.requires_approval: agr.wait_for_approval(result.approval_id)

ALLOW

Policy passes, risk is low. Agent executes immediately. Decision cached 60 seconds. Audit event written.

APPROVAL REQUIRED

Risk threshold crossed or policy requires human sign-off. Email + Slack sent. Agent waits. 48-hour durable workflow via Temporal.

DENY

Policy explicitly forbids the action. Agent is blocked immediately. Reason returned. Audit event written with full context.
