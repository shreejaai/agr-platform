# Wave 1 Plan A — Cedar CLI End-to-End + OpenAPI Docs

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Cedar CLI the verified primary evaluation engine (with tests proving it works), and produce a rich OpenAPI spec that developers can use to self-onboard.

**Architecture:**
- Cedar CLI is already structurally wired in `packages/agr-core/policy_engine.py` and the Dockerfile. The gap is zero test coverage for the cedar_cli code path, no way to install cedar locally, and no CI step that installs cedar and runs cedar-specific tests.
- OpenAPI is auto-generated by FastAPI at `/docs` and `/openapi.json`. The gap is that schemas lack `description`/`example` fields, routes lack docstrings, and there is no committed `openapi.json` file or CI step to keep it current.

**Tech Stack:** Python 3.12, FastAPI 0.115, Pydantic v2, `cedar-policy-cli` (Rust binary via cargo/brew), pytest, GitHub Actions

```python
@cedar_required
def test_cedar_authorize_raw_output_is_allow_or_deny() -> None:
    """Smoke test: raw subprocess stdout must be exactly 'ALLOW' or 'DENY'."""
    import json
    import subprocess
    import tempfile
    from pathlib import Path

    binary = _find_cedar_cli()
    assert binary is not None

    policy_text = 'permit(principal, action == Action::"read", resource);'
    entities = [
        {"uid": {"type": "Agent", "id": "a"}, "attrs": {}, "parents": []},
        {"uid": {"type": "Resource", "id": "r"}, "attrs": {}, "parents": []},
    ]
    request = {
        "principal": {"type": "Agent", "id": "a"},
        "action": {"type": "Action", "id": "read"},
        "resource": {"type": "Resource", "id": "r"},
        "context": {},
    }
    with tempfile.TemporaryDirectory() as tmpdir:
        p = Path(tmpdir)
        (p / "pol.cedar").write_text(policy_text)
        (p / "ent.json").write_text(json.dumps(entities))
        proc = subprocess.run(
            [binary, "authorize",
             "--policies", str(p / "pol.cedar"),
             "--entities", str(p / "ent.json"),
             "--request-json", json.dumps(request)],
            capture_output=True, text=True, timeout=5.0,
        )
    output = proc.stdout.strip()
    assert output in ("ALLOW", "DENY"), (
        f"Unexpected cedar output: stdout={proc.stdout!r} stderr={proc.stderr!r} exit={proc.returncode}"
    )
```
