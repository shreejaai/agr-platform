# AGR Architecture Principles

1. Deny by default — no execution without explicit allow
2. Runtime enforcement — decisions happen at execution time
3. Deterministic risk scoring — reproducible safety decisions
4. Human escalation — sensitive actions require approval
5. Policy as data — no hardcoded business rules
6. Audit everything — every decision must be logged
7. Fail closed — uncertainty results in denial or escalation
8. Modular services — clear boundaries between components
9. Cross-language compatibility — Python + TypeScript first
10. Observable system — traceable decisions and events
